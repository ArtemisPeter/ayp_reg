# The gate scanner keeps working without internet

The Security page downloads the list of valid Camp IDs before the gate opens, records Gate Scans on the phone while offline, and uploads them when the connection returns. We chose this over an online-only scanner because a dead gate with about 6,000 people passing through costs far more than the extra build effort. Attendees registered On-Site by CSV during an outage are not on the phone's list until the next download, so Security lets them in by name and the Secretary corrects the record later.
